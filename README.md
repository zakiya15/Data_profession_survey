# Data Professional Survey Breakdown Dashboard
This Power BI dashboard analyzes survey responses from data professionals worldwide.
The dashboard provides insights into:
- Average salaries
- Job roles
- Programming languages used
- Work-life balance
- Country-wise distribution
- Career satisfaction

## Problem Statement
Data professionals work in various roles such as Data Analyst, Data Scientist, Data Engineer, and Business Analyst.
<br>The objective of this project is to analyze survey responses and identify:
- Which roles earn the highest salaries
- Popular programming languages among professionals
- Work-life balance satisfaction levels
- Country-wise trends in the data industry
- Factors affecting career happiness

## Dataset
<br>Source: Alex The Analyst Power BI [Data_Professional_Survey.xlsx](https://github.com/user-attachments/files/28701656/Data_Professional_Survey.xlsx) Dataset
<br>Records: Survey responses from data professionals
<br>Features include:
- Job Title
- Salary
- Country
- Favorite Programming Language
- Work/Life Balance Rating
- Salary Satisfaction Rating

## Data Cleaning
<br>Performed in Power Query:
- Removed unnecessary columns
- Standardized country names
- Cleaned salary values
- Handled null values
- Created transformed fields for analysis

## Dashboard Features
- Average Salary by Job Title
- Country Distribution
- Favorite Programming Language Analysis
- Work-Life Balance Ratings
- Salary Satisfaction Analysis
